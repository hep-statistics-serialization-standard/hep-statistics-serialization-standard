## Domains {#sec:domains} 
The top-level component `domains` contains an array of domains giving information on the ranges of parameters and variables in struct format. Within a specified domain, the corresponding model is expected to yield valid values. Each domain must contain a `name` and a `type` although right now only the `product_domain` type is supported, even though others like e. g.&nbsp;a simplex domain might be added later. A domain consists of the following components: 

-   `name`: custom string 
-   `type`: `product_domain` 
-   `axes`: array of parameters and variables in this domain in terms of individual axes. These can be continuous or categorical, mirroring the axis types defined in [Axis Specifications](#sec:axes){reference-type="ref" reference="sec:axes"}.
    -   A continuous axis has the components:  
        -   `name`: custom string
        -   `max`: upper bound of range 
        -   `min`: lower bound of range.
    -   A categorical axis has the components: 
        - `name`: custom string
        - `categories`: array of unique strings enumerating the allowed values

```json title="Example: Domains"
"domains":[ 
  { 
    "name":"domain1", 
    "type":"product_domain", 
    "axes": [ 
      { "name" : "par_1", "min" : 1, "max" : 8 }, 
      { "name" : "par_2", "min" : 4.78, "max" : 6 }, 
      { "name" : "channel", "categories": ["SR","CR"] }, 
      ... 
    ] 
  }, 
  ... 
]
``` 

### Parameters without a domain {#sec:parameters-without-domain}
A parameter on which a distribution or function depends, but which is not listed as an axis of any `product_domain` in the document, is **constant**. It is not varied by fits, scans or samplers, and takes the value given in the parameter point in use (see [Parameter points](#sec:parameterpoints){reference-type="ref" reference="sec:parameterpoints"}). If no parameter point in use assigns a value to it, the document is invalid for any analysis that depends on that parameter.

A parameter that is listed as an axis of at least one domain is free by default. Setting `const` to `true` for it in a parameter point makes it constant whenever that parameter point is used, regardless of the domains. The converse does not hold: `const` set to `false` (or omitted) does **not** make a parameter without a domain free, since there is no range in which it could be varied.

```json title="Example: Free and constant parameters"
"domains": [ { "name": "domain1", "type": "product_domain",
               "axes": [ { "name": "par_1", "min": 0, "max": 10 },
                         { "name": "par_3", "min": 0, "max": 10 } ] } ],
"parameter_points": [ { "name": "starting_values", "parameters": [
  { "name": "par_1", "value": 1 },               // in a domain: free
  { "name": "par_2", "value": 2 },               // in no domain: constant
  { "name": "par_3", "value": 3, "const": true } // in a domain, but constant for this point
] } ]
```

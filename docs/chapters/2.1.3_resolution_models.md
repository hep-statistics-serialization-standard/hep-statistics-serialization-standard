### Resolution models {#sec:resolution-models label="sec:resolution-models"}

Resolution models are distribution objects that describe the smearing kernel
of an
[`analytic_convolution_dist`](#dist:analytic-convolution). They are stored in
the top-level `distributions` array and are referenced by name through the
`resolution_model` component.

For a convolution variate $x$, a resolution model defines a normalized kernel
$R(r)$ in the residual $r=x-u$. Its normalization is over the full real line,
even when the current domain of $x$ is bounded. The analytic convolution
distribution applies its own normalization over the current HS<sup>3</sup>
domain after convolution. Resolution models are never extended.

#### Gaussian resolution model

The Gaussian resolution model is

$$
\begin{aligned}
R(r;\mu,\sigma) =
\frac{1}{\sigma\sqrt{2\pi}}
\exp\left[-\frac{(r-\mu)^2}{2\sigma^2}\right].
\end{aligned}
$$

-   `name`: custom unique string
-   `type`: `gaussian_resolution_model`
-   `x`: name of the convolution variate $x$
-   `mean`: number or name of a real-valued parameter or function $\mu$
-   `sigma`: positive number or name of a positive real-valued parameter or
    function $\sigma$

The mean and width [must]{.smallcaps} be independent of `x`.

#### Delta resolution model

The delta resolution model represents perfect resolution,

$$
R(r)=\delta(r),
$$

and is the identity element of convolution.

-   `name`: custom unique string
-   `type`: `delta_resolution_model`
-   `x`: name of the convolution variate $x$

The following example is a one-term, two-sided decay with perfect resolution:

```json title="Example: Two-sided decay"
{
  "distributions": [
    {
      "name": "perfect_resolution",
      "type": "delta_resolution_model",
      "x": "decay_time"
    },
    {
      "name": "two_sided_decay",
      "type": "analytic_convolution_dist",
      "x": "decay_time",
      "resolution_model": "perfect_resolution",
      "terms": [
        {
          "coefficient": 1.0,
          "basis": {
            "type": "exp_decay",
            "decay_constant": "lifetime",
            "side": "both"
          }
        }
      ]
    }
  ]
}
```

#### Mixture resolution model

A mixture resolution model is a convex mixture of resolution models that
share the same convolution variate:

$$
R(r)=\sum_{i=1}^{n}w_i R_i(r),
\qquad w_i\geq 0,
\qquad \sum_{i=1}^{n}w_i=1.
$$

-   `name`: custom unique string
-   `type`: `mixture_resolution_model`
-   `x`: name of the convolution variate $x$
-   `summands`: non-empty array of names referencing resolution models. Every
    summand [must]{.smallcaps} use the same `x` and support all bases with
    which the mixture is used.
-   `coefficients`: array of non-negative numbers or names of non-negative
    real-valued parameters or functions $w_i$. Coefficients
    [must]{.smallcaps} be independent of `x`.

For $n$ summands, `coefficients` [must]{.smallcaps} contain either $n$ or
$n-1$ entries. If all $n$ coefficients are present, their sum
[must]{.smallcaps} be one. If $n-1$ are present, the final coefficient is

$$
w_n=1-\sum_{i=1}^{n-1}w_i
$$

and [must]{.smallcaps} also be non-negative. These constraints apply at every
allowed parameter point.

```json title="Example: Mixture resolution model"
{
  "distributions": [
    {
      "name": "resolution_core",
      "type": "gaussian_resolution_model",
      "x": "decay_time",
      "mean": 0.0,
      "sigma": "core_width"
    },
    {
      "name": "resolution_tail",
      "type": "gaussian_resolution_model",
      "x": "decay_time",
      "mean": 0.0,
      "sigma": "tail_width"
    },
    {
      "name": "time_resolution",
      "type": "mixture_resolution_model",
      "x": "decay_time",
      "summands": ["resolution_core", "resolution_tail"],
      "coefficients": ["core_fraction"]
    }
  ]
}
```

A resolution model is invalid if its `x` differs from the convolution variate
of a distribution that references it. A Gaussian resolution model with a
non-positive width is invalid. A mixture resolution model is invalid if it has
no summands, if its summands do not share `x`, if the number of coefficients
is not $n$ or $n-1$, or if any explicit or implicit weight is negative or the
explicit weights do not sum to one.

#### Migration from superseded types

The special-case types in the following table are replaced by the canonical
types in this section and by `analytic_convolution_dist`. They are not aliases.

| Superseded type | Canonical representation |
|---|---|
| `decay_dist` | One-term `analytic_convolution_dist` with an `exp_decay` basis. Rename `t` to `x`, `tau` to `decay_constant`, and `resolutionModel` to `resolution_model`. Map `decayType` values `0`, `1`, and `2` to sides `positive`, `both`, and `negative`, respectively. |
| `gauss_model_function` | `gaussian_resolution_model` with the same `x`, `mean`, and `sigma`. |
| `truth_model_function` | `delta_resolution_model` with the same `x`. |
| `mixture_model` | `mixture_resolution_model` when all summands are resolution models. Non-extended normalized coefficients translate directly. If the former model encoded an event yield, separate its total coefficient sum as the `rate` of a `rate_extended_dist` around the final physics distribution and divide the resolution weights by that sum. |
